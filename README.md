# ARQUITECTURA y Lenguajes WEB

## INTERNET
Red de redes que conecta todo los dispositivos.

## Pagina
Un documento, un conjunto de paginas relacionadas.

## Recurso
Cualquier archivo que usa la web: texto, imagen, estilo, programa.

## URL
La direccion de un recurso. Lo que escribes en la barra.

## Navegador
Programa que abre y muestra paginas:
Chrome, Firefox, Edge, Safari.

El internet es todo aquel que nos da el acceso a los sitios web de busqueda y el sitio web es aquellla pagina que nos dan la informacion acerca de la busqueda.
